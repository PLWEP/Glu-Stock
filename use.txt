# ️ GLU-STOCK v18.26: KAGGLE DEPLOYMENT GUIDE

Panduan resmi setup dan operasional Glu-Stock "CNN-LLM Dual Core" di lingkungan Kaggle.

## 1. Persiapan Secrets (Add-ons > Secrets)
Daftarkan 3 kunci ini di Kaggle Secrets:
*   `FIREBASE_KEY_JSON`: Seluruh isi file JSON Service Account dari Firebase.
*   `TELEGRAM_TOKEN`: Bot Token dari @BotFather.
*   `TELEGRAM_CHAT_ID`: Chat ID tujuan laporan.
*   `HF_TOKEN`: Hugging Face Token (Read Access) untuk download model Gemma.

## 2. Persiapan Model & Input (Kaggle Dataset)
Upload file ini sebagai Dataset (Urgent untuk CNN):
*   `cnn_daily_t2.tflite` (Hanya ini yang dibutuhkan)
Catatan: Model LGBM sudah tidak digunakan dan bisa dihapus dari dataset.
